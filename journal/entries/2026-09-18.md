## Continued, Phase 2 done

Routine Machine's Phase 2 was built and pushed: a `GET /patterns` endpoint in the
intelligence service computing completion rates, streaks, skip-heavy days, and a descriptive
correlation between logging a learning topic and completing routine items, all as pure
functions over data already available from the backend. No new backend endpoint was needed,
one existing response gained a field (`createdAt`) that Phase 2's date-windowing required.

Two things worth recording plainly rather than folding into a status line. First, before

backdated before its routine item existed. That's now twice a bug surfaced through actually
running the system rather than through the test suite alone, worth watching as a real
pattern in how this gets built, not a coincidence yet, but worth naming.
