# Settlement Engine

## What it is

An Idempotent Settlement and Reconciliation Engine, with invoice financing as the application
layer. A portfolio project built for fintech backend roles, specifically Ezra.

## Stack

Monorepo. Java Spring Boot, PostgreSQL, Kafka, Python/FastAPI for fraud detection, Next.js,
Kubernetes. Observability with Prometheus, Grafana, OpenTelemetry.

## Status

Architecture and multi-file documentation system fully designed. Phase 1 not yet started.

## Next step

Start Phase 1. Which piece first is still open: the core settlement logic, the idempotency
layer, or the reconciliation job. Decide and record the reasoning here when that decision
gets made.
